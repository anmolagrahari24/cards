# 🃏 Cards

A simple and responsive **Cards UI Project** built using frontend web technologies. This project focuses on creating attractive and reusable card layouts with a clean and user-friendly interface.

## 🚀 Features

* 🃏 Attractive card design
* 🎨 Clean and modern UI
* 📱 Responsive layout
* 🖼️ Image-based card components
* ✨ Simple hover effects
* 💻 User-friendly interface
* 🔧 Easy to customize

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* Responsive Design
* Git & GitHub

## 📂 Project Structure

```text
cards/
│
├── index.html
├── style.css
├── script.js
├── assets/
└── README.md
```

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/anmolagrahari24/cards.git
```

### 2. Navigate to the project

```bash
cd cards
```

### 3. Run the project

Open the `index.html` file in your browser.

## 🎯 Project Purpose

This project was created to practice **HTML structure, CSS styling, Flexbox, responsive layouts, UI design, and reusable card components**.
